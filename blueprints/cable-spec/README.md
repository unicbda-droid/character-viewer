# Abgeschirmte Kabel - Spezifikation

## Kabel-Typen im Vergleich

```
                    Kupfer              Glasfaser
                    ──────              ─────────
DP 2.1:             max 2m              max 30m
HDMI 2.1:           max 3m              max 30m
USB-C:              max 1m              max 20m
Signalqualitaet:    gut (EMI-abhaengig) perfekt (keine EMI)
Preis:              $8-20               $30-80
Empfehlung:         Kurze Distanzen    Lange Distanzen + Home-Cinema
```

GLASFASER = SAUBERSTES BILD:
  - Kein Signalverlust
  - Keine elektromagnetische Interferenz (EMI)
  - Keine Rueckkopplung
  - Konstante Bandbreite ueber ganze Laenge
  - Ideal fuer: 4K@240Hz, 8K@60Hz+, VR-Headsets
  - Nachteil: Teurer, Stecker empfindlicher

KUPFER = STANDARD:
  - Gut fuer kurze Distanzen (<1m)
  - Billiger
  - Ueberall verfuegbar
  - Nachteil: Signalverlust ab 2m, EMI-stoeranfaellig

```
Spec:
  Standard:    DisplayPort 2.1 UHBR20
  Bandbreite:  80 Gbps
  Abschirmung: Doppelt (Foil + Braid)
  Draht:       28 AWG
  Stecker:     Vergoldet
  Typ:         Active (mit Controller Chip)
  Laenge:      1m / 2m
  Preis:       $8-15 (Herstellung)
  Verkauf:     $30-50

Zertifizierung:
  - VESA Certified DP 2.1
  - FCC Class B
  - CE (EU)
  - RoHS
```
