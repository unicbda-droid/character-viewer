# Kuenstliche Limitierungen bei Konsolen

## Das Problem

Hersteller limitieren Hardware absichtlich:
- PS5 Pro: 120Hz上限 obwohl Hardware mehr kann
- Switch 2: 1080p/30fps, obwohl Tegra X1 4K kann
- Xbox: HDMI 2.1 aber kein DisplayPort = kein Monitor-Betrieb

## Liste der Limitierungen

```
SONY PS5 / PS5 Pro:
  - Max 120fps (softwareseitig)
  - Kein 50Hz-Modus
  - Kein DisplayPort
  - Kein FreeSync/G-Sync
  - Nicht upgradebar (RAM, SSD limitiert)
  - Proprietaeres DualSense Feature-Sperren

MICROSOFT XBOX SERIES X:
  - Max 120fps
  - Kein DisplayPort
  - Kein 50Hz-Modus
  - Proprietaere SSD (Seagate Expansion)
  - Quick Resume frisst RAM

NINTENDO SWITCH 2:
  - Max 1080p handheld / 4K docked (upscaled)
  - Max 30fps in vielen Spielen
  - Tegra X1 kann mehr
  - Keine Freiheit bei Einstellungen

AMD RADEON / NVIDIA GeForce:
  - Driver-Lock-in (nur eigene GPUs)
  - Kein Open-Source Standard
  - proprietäre APIs (DLSS vs FSR)
  - Kein Upgrade-Pfad

INTELLIGENT DESIGN (NVIDIA):
  - Kein VRAM-Upgrade moeglich
  - 12VHPWR Kabel-Problem
  - Geplante Obsoleszenz
```

## GTA6 Europa: Keine Limitierungen

```
DISPLAY:
  - DisplayPort 2.1 (kein HDMI-Lock)
  - 4K@240Hz, 8K@60Hz
  - 50Hz/100Hz PAL nativ
  - FreeSync + G-Sync
  - VRR (50-240Hz variabel)

HARDWARE:
  - RAM upgradebar (SO-DIMM Slot)
  - SSD upgradebar (M.2 NVMe)
  - GPU austauschbar (PCIe)
  - Kuehlung austauschbar (Quick-Connect)
  - Gehaeuse parametrisch (FreeCAD)

SOFTWARE:
  - Kein Vendor-Lock
  - Beliebiges OS (Linux, Windows, BSD)
  - Open-Source Treiber
  - Kein DRM noetig

PREIS:
  - Herstellungskosten transparent
  - Kein kuenstlicher Aufschlag
  - Jeder kann selbst bauen oder kaufen
```
