# Abgeschirmte Kabel-Spezifikation

## Warum abgeschirmte Kabel?

```
PROBLEM:
  - Hohe Datenraten (80 Gbps bei DP 2.1)
  - Elektromagnetische Interferenzen (EMI)
  - Billige Kabel verursachen Signalverlust
  - Bei 8K: Jedes dB zaehlt
  
LOESUNG:
  - Doppelte Abschirmung (Foil + Braid)
  - Goldkontakt-Stecker
  - Aktive Verstaerkung (bei langen Kabeln)
  - VESA-zertifiziert
```

## Kabel-Specs

```
DP 2.1 Cable (1m):
  Bandbreite: 80 Gbps (UHBR20)
  Abschirmung: Doppelt (Foil + Braid)
  Stecker: Vergoldet
  Draht: 28 AWG
  Typ: Active (mit Controller)
  Preis: $8-15 (Herstellung)
  Verkauf: $30-50

DP 2.1 Cable (2m):
  Bandbreite: 80 Gbps (UHBR20)
  Abschirmung: Doppelt
  Typ: Active (noetig ab 1.5m)
  Preis: $12-20 (Herstellung)
  Verkauf: $40-70

HDMI 2.1 Cable (2m):
  Bandbreite: 48 Gbps
  Abschirmung: Einfach
  Typ: Passive
  Preis: $3-5
  Verkauf: $15-25

USB-C 4.0 Cable (1m):
  Bandbreite: 40 Gbps
  Abschirmung: Doppelt
  Typ: Active
  Preis: $4-6
  Verkauf: $15-20
```
