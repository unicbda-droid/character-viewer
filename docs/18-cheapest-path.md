## Falls kein Geld vorhanden

```
OPTION 1: VORBESTELLUNG
  - eBay Listing erstellen
  - Kaeufer bezahlen
  - Damit Einkauf finanzieren
  - Modul innerhalb von 7-14 Tagen liefern
  - RISIKO: Wenn Lieferung laenger dauert = negative Bewertung

OPTION 2: LEIHE/KLEINKREDIT
  - €200-800 leihen
  - 10-50 Module kaufen
  - Verkaufen
  - Zurueckzahlen + Gewinn behalten

OPTION 3: DROPSHIPPING
  - Gar nichts kaufen
  - Kaeufer bestellen bei dir
  - Du bestellst bei Kedun/Digiera
  - Lieferung direkt an Kaeufer
  - RISIKO: Kein Kontrolle über Qualitaet/Lieferung
```
