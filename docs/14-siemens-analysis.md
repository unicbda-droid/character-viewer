# Siemens & GTA6 Europa

## Kurzantwort

```
Siemens:     Kein DRAM-Hersteller mehr (seit 1999)
Koennte:     PCB-Montage in Amberg/Karlsruhe
Bietet:      EDA-Tools (Chipdesign), Fertigungssoftware
Realitaet:   Siemens macht keine Speicher-Module
```

---

## Siemens Geschichte mit Speicher

```
1949:  Siemens beginnt Halbleiter-Forschung
1963:  IC-Produktion startet
1994:  Dresden Fab (wird spaeter Infineon)
1998:  DRAM-Markt crasht, $674M Verlust
1999:  Infineon abgespalten ("Europas groesster Tech-Spin-off")
2006:  Infineon spaltet Qimonda ab (DRAM)
2009:  Qimonda pleite - DE verliert DRAM-Produktion
2024:  Infineon zahlt €800M Schiedsspruch (Qimonda-Restschulden)
```

**Siemens hatte DRAM, hat es aber verkauft/abgespalten. Heute: kein Speicher mehr.**

## Was Siemens HEUTE macht

### EDA-Tools (Chipdesign-Software)

```
SIEMENS EDA (frueher Mentor Graphics)
  - Eines von 3 grossen EDA-Unternehmen
  - Calibre (Verifikation) - INDUSTRY STANDARD
  - Questa (Simulation)
  - Catapult (HLS)
  - Aprisa (Physical Implementation)
  
  Koennte fuer GTA6 Europa relevant sein:
  - PCB-Design mit Xpedition/PADS
  - Signal-Integrity-Analyse
  - DRC/LVS fuer komplexe Boards
```

### Elektronik-Fertigung in Deutschland

```
AMBERG, Bayern
  - 4.500 Mitarbeiter
  - €200M neue Fabrik (bis 2030)
  - Cleanroom fuer Elektronik
  - Smart Factory mit KI + humanoiden Robotern
  - Produziert: Controller, Schalter, Schutzgeraete
  
KARLSRUHE, Baden-Wuerttemberg
  - 1.000 Mitarbeiter
  - 37.000 m2 Produktion
  - 24.000 Produktvarianten
  - Produziert: Controller, WLAN-Router, Industrie-PCs
```

**Siemens koennte theoretisch GTA6-Board-Montage in Amberg machen.**
Aber: Siemens montiert primaer EIGENE Produkte, keine Fremdaufträge.

### Software fuer Fertigung

```
VALOR:  PCB-Montage-Optimierung

## Relevanz fuer GTA6 Europa

```
KANN SIEMENS HELFEN?
  EDA-Tools:          JA - PCB-Design, Signal Integrity
  Fertigung:          THEORETISCH - Amberg hat Kapazitaet
  DRAM-Chips:         NEIN - keine Fabs mehr
  Investition:        UNSICHER - Siemens istgross, Projekt ist klein

WAS MAN KONNTE VERSUCHEN:
  1. Siemens EDA Lizenzen fuer PCB-Design (kostenpflichtig)
