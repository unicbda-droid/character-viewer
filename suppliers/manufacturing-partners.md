## EMPFEHLUNG - Kaufmanns-Weg

```
SCHRITT 1: PCB bestellen
  -> JLCPCB (China, $10-30 pro Board)
  -> ODER Eurocircuits (EU, $80-200 pro Board)

SCHRITT 2: Komponenten kaufen
  -> Digikey/Mouser (PMIC, SPD, Passives)
  -> Alibaba/Shenzhen Kedun (DRAM Chips, $10-15)
  -> ODER Digiera als Komplett-OEM ($12-18 pro Modul)

SCHRITT 3: Bestueckung
  -> JLCPCB SMT Assembly ($2-5 pro Board)
  -> ODER Digiera/NexaRAM als ODM (komplett)

SCHRITT 4: Verkauf
  -> eBay, Amazon, B2B
  -> Preis: $50-80 pro 32GB Modul
  -> Gewinn: $30-60 pro Stueck
```
